## Service value chain

Every piece of work sits on one or more of these. Name the activity in the record if it helps; skip it if it does not.

| Activity | Meaning | Typical trigger |
|----------|---------|-----------------|
| Plan | Understand current state, direction, what to do | Priority, SLA review, lock plan |
| Improve | Make it better on purpose | CSI item |
| Engage | Listen, talk, capture demand | Desk, Olivia mail, calendar |
| Design and transition | Shape something new or changed so it can run | New skill, new stack, domain |
| Obtain/build | Get or make the thing | Code, compose, buy |
| Deliver and support | Run it and restore it | Incident, request, event |

Demand enters at **Engage**. Restore lives in **Deliver and support**. A permanent fix often needs **Obtain/build** plus a **Change**.
